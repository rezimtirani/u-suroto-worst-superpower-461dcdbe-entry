One invented superpower, one line, as useless as it gets: I can summon a chair whenever I sit down — but it only appears three seconds after I have already hit the floor.

> I can summon a chair whenever I sit down, but it only appears three seconds after I've already hit the floor.

## How it works

`main.py` (Python 3 standard library only) writes the superpower to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line, and a turn in the same breath — the power, then the reason it is useless.

```sh
python3 main.py
```
